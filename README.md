# SongforMe 的 QQ 音乐插件

给 [SongforMe](https://github.com/SansOfficial/SongforMe) 用的社区插件。**非官方**，和 QQ 音乐、腾讯没有关系。

## 添加

需要 SongforMe 1.2 或更新。点左下角“音源 → 添加插件…”，粘贴这个链接：

```
https://github.com/SansOfficial/songforme-qq-music/blob/main/qq-music.js
```

确认后会打开 y.qq.com，用 QQ 或微信扫码登录。更新插件时再添加一次同样的链接。

## 能做什么

- 登录后：搜索、播放、歌词，同步“我喜欢”、自建和收藏的歌单、最近播放，推荐。
- 不登录：粘贴歌单链接导入，只列免费歌。
- 喜欢、歌单的改动只记在本机，不写回账号。

## 边界

- 只播放你的账号本来就有权播放的歌，会员歌要账号是会员；不下载、不解密、不绕过会员限制。
- 登录在官方网页里完成，登录状态由应用保存，只发给 u.y.qq.com，插件读不到。
- 用的是网页端接口，可能随时失效，也可能不符合 QQ 音乐的用户协议。请只供个人低频使用，风险自己承担。

登录后的功能刚写好，试过的账号还不多，遇到问题请提 issue（不要贴 cookie、账号）。
